# 大小模型协同的视频分析系统架构设计

本项目旨在构建一个**云边协同（Cloud-Edge Collaboration）**的视频分析平台。在边缘侧使用轻量的 C++ 程序（当前仓库的 Video Sentinel）及小模型完成高并发、高实时的视频流接入与目标检测；在云端通过 Java + React 构建集中管控平台，并接入多模态大模型进行深度的图片/视频理解与安全预警。

---

## 1. 整体架构分层 (Cloud-Edge-Client)

系统整体划分为以下几个核心层级：

1. **边缘计算层 (Edge Computing Layer)**：部署在现场的设备（如 Orange Pi AI Pro）。负责实时视频接入、小模型推理、基础事件过滤、视频推流。
2. **中心控制层 (Central Control Layer)**：部署在云端的 Java 后端服务。负责全局设备管理、小模型训练、任务下发、视频流分发。
3. **大模型理解层 (Large Model Layer)**：部署在云端或接入第三方云服务（如 GPT-4V, Qwen-VL 等）。负责接收边缘端上报的复杂事件截图，进行二次推理、深度语境分析。
4. **展示交互层 (Presentation Layer)**：基于 React 的前端 Web 看板，供管理员、安保人员查看实时监控、处理告警、管理模型和任务。

---

## 2. 中心管控平台 (Cloud Platform)
采用前后端分离架构，作为整个系统的“指挥中心”。

### 2.1 前端应用 (React)
- **实时监控看板**：集成 WebRTC / FLV 播放器，实时拉取并展示边缘端传回的视频流（带或不带 AI 识别框）。
- **告警中心**：展示由边缘端和小模型初筛，或大模型深度分析后产生的高级别告警卡片（含关键帧截图、时间、地点、事件描述）。
- **任务编排**：为边缘节点配置监控任务（例如画 ROI 区域、设置报警时间段、配置检测目标等）。
- **模型管理界面**：上传数据集、触发训练任务，并一键推送到指定的边缘设备。

### 2.2 后端服务 (Java / Spring Boot)
- **设备与任务管理**：维持与边缘终端的连接（如通过 MQTT 或 WebSocket），管理设备在线状态，下发告警规则和配置（派发任务）。
- **流媒体网关控制**：调度和管理来自边缘端的实时视频串流（建议配合 SRS / MediaMTX 等流媒体服务器）。
- **模型训练平台接入**：调用底层训练脚本完成 YOLO 模型的训练、导出和转换（如转为 Ascend `.om` 格式）。
- **OTA 与模型下发**：提供安全的双向通道，将训练好的小模型推送到指定的边缘设备上并触发重载。
- **业务数据库**：存储历史告警事件、设备台账、用户权限等。

---

## 3. 边缘计算终端 (Edge Node - Video Sentinel)
当前 C++ 仓库的核心部分，作为系统的前哨。

- **视频摄入与串流**：通过 V4L2 接入本地摄像头，或者拉取本地局域网 RTSP 流。支持将实时处理后的视频流（通过内嵌流媒体协议，或外推到云端）实时回传给控制平台。
- **小模型推理 (Small Model)**：运行云平台下发的 YOLO 模型，通过 DVPP + AscendCL 硬件加速，实时框出人、车、物。
- **规则引擎**：执行云端派发的监控任务（如 ROI 区域入侵、越线检测）。
- **事件生成与上报**：发生异常时，截取关键帧（Snapshot）与元数据（发生时间、目标坐标），打包上报给云端 Java 平台。

---

## 4. 大模型分析系统 (Large Model Subsystem)
作为“大脑”，处理小模型搞不定的长尾问题或复杂逻辑。

- **多模态接口接入**：云端 Java 服务收到边缘节点上传的特定告警图片后，调用大模型 API。
- **复杂安全预警**：
  - *场景判断*：例如小模型只识别出了“人”和“明火”，大模型负责判定这是“工人在进行安全焊接”还是“发生了火灾险情”。
  - *动作理解*：判断人员是否发生斗殴、跌倒、或者未佩戴安全帽等复杂语义动作。
- **自然语言告警生成**：大模型生成一段连贯的描述（如：“摄像头A检测到区域B有一名穿红色外套的人员正在攀爬围栏”），并打上危险等级标签。

---

## 5. 数据与控制数据流向

1. **下行控制流**：React 前端 -> Java 后端 -> 边缘端（下发新 YOLO 模型、下发监控任务配置）。
2. **上行告警流**：边缘端（产生事件截图） -> Java 后端 -> 大模型（多模态分析） -> Java 后端（入库） -> React 前端（推送安全预警）。
3. **上行视频流**：边缘端 -> 流媒体服务器 (如 SRS/MediaMTX) -> React 前端。
